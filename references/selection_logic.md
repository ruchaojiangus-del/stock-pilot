# 强势波段行情选股逻辑摘要

本 Skill 根据用户提供的《选股逻辑思维文档》实现。量化实现只使用 API 返回的数据，不补编缺失字段。

## 核心关键逻辑

1. 环境定仓：包含3级。1级为指数站上MA13、MA13向上且量能不弱；2级为指数围绕MA13震荡或量能一般；3级为指数跌破MA13且趋势/量能偏弱。
2. 题材定级：S级方向包含航空航天、人工智能、可控核聚变、6G、量子科技、脑机接口、低空经济、国防军工、海南封关等；A级包含存储芯片、PCB、固态电池等；B级包含特斯拉、英伟达、苹果、关税、战争、降息等。
3. 技术筛选：日线MA13向上、周线MA13向上、股价处于历史偏低位；量能温和放大；涨停或跳空大阳/反包/多堆量；股性活跃，年涨停次数大于3；基本面要求50亿<市值<200亿、盈利能力为正。

## 核心交易系统

1. 选股池：自选股、强势股、波段鱼池。脚本支持 `--watchlist` 导入自选股，并从涨停池、题材池、涨幅榜和成交额榜构建候选。
2. 买点：股价回踩MA13、MA5上穿或保持在MA13上方、日线MACD不下0轴、60分钟MACD在0轴上方、60分钟MA13重新向上。
3. 持股：动态监控60分钟MA13趋势不破、量价健康、不出现明显见顶信号。
4. 止损：60分钟MA13跌破不能收回、60分钟MA5下穿MA13、最近放量凸量柱底跌破。
5. 止盈：涨幅超30%、阶段大量滞涨、连续冲高回落、60分钟远离MA5后不创新高等。

## 实现上的量化近似

- “MA13斜率>45度”转换为归一化MA13斜率阈值，避免用主观图形角度制造伪精确。
- “盈利能力为正”用实时行情可得的正市盈率作为代理指标；若PE缺失，输出风险而不编造。
- “题材定级”通过 AKShare 东方财富概念板块名称关键词和成份股匹配实现；不同数据源口径可能导致漏匹配。
- 候选不足3只时，脚本会显示高分但未通过项及风险，不会为了凑数编造股票。
